# Code of conduct

CaptchaLab is a learning and research project. We want it to be a respectful, welcoming place to ask questions and contribute, whatever your background or experience level.

## Expected behavior

- Be respectful and assume good faith. Disagree with ideas, not with people.
- Give and accept constructive feedback; keep reviews about the code and the design.
- Be patient with newcomers and with non-native English speakers.
- Respect privacy: never share other people's personal data or interaction recordings.

## Not acceptable

- Harassment, insults, discrimination or personal attacks.
- Publishing someone else's private information.
- Sexualized language or imagery, or unwelcome attention.
- Using the project to plan or share ways to attack, bypass or abuse real services (see the scope rules in [CONTRIBUTING.md](CONTRIBUTING.md)).

## Enforcement

Maintainers may remove comments, close discussions, or restrict participation when behavior breaks these rules. To report a problem, use GitHub's private reporting options for this repository, or ask in an issue for a private channel without describing the incident publicly. Reports are handled with discretion.

This code of conduct applies in the repository, issues, pull requests and any other space where the project is represented.
