# CaptchaLab v0.7.0-alpha

The Behavioral Lab, Compare, the challenge builder and the experiment workspace now cover **eleven of the twelve** CAPTCHAs.

## New

- **Five more CAPTCHAs in the lab**: Shape Matching, Math / Logic, Sequence (typed and visual variants), Memory (sequence and position variants) and Audio. Each reports behavioral signals, has three deterministic synthetic profiles, and has its own classifier rules. Two signals are new: *Wrong attempts* and *Plays*.
- Compare, the builder and Experiments list all eleven, with the same flow as before: record, generate a synthetic sample on exactly the same challenge, compare, inspect the evidence, export and import. These CAPTCHAs have no path to draw, so they compare timelines.
- **Memory** is analysed from the moment recall begins: only recall actions count, and a synthetic Memory session is always measured in its own recall context. The context travels in session files and bundles as `recallStartMs`.
- **Proof of Work is left out on purpose**: its measurements describe your device's computation, not an interaction.
- The Playground Session components of the five CAPTCHAs gained the same optional `onResult`, `onReset` and `showInspect` props as before; nothing changes when they are not used.

## Unchanged

The classifier is still `behavioral-baseline@1`. The rules and ranges of the six CAPTCHAs of v0.5 are byte-identical to that release (a test pins their checksum), so no existing result changed; the new rule sets only add. Signals stay `behavior-signals@1` and the generator `synthetic@1`; the file formats stay version 1 (their `captcha` list simply grew and Memory sessions carry `recallStartMs`). No backend, no analytics, no automatic storage, no fingerprinting.

## Limitations

The new rules are hand-set like the others and the lab still has no validated human data or accuracy figure. Some generated profiles read as Human-like or Uncertain; that is shown on purpose. Proof of Work has no behavioral coverage. See `docs/behavioral-lab.md` and `docs/technical-debt.md`.
