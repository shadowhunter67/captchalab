# CaptchaLab v0.5.0-alpha

CaptchaLab becomes a small behavioral research lab: record an attempt, compare it with a generated synthetic one on the same challenge, and see how an **experimental** rule baseline reads both.

## New

- **Behavioral Lab** (`/behavior`): what the lab does and does not do, the six supported CAPTCHAs, signal groups (Timing, Motion, Correction, Rhythm, Attempts, Input) and a signal explorer that shows each CAPTCHA's signals and the classifier's configured ranges.
- **Richer Compare** (`/compare?captcha=<id>`): Slider, Drag & Drop, Checkbox, Image Grid, Text and Rotation. Pick the CAPTCHA, variant, difficulty and seed, complete the challenge, pick a synthetic profile and press *Generate comparison*. Both sides always use the same challenge. You get a signal table with differences (no colours, no verdicts), descriptive observations, a trajectory view (Slider, Drag & Drop, Rotation) or a timing view (Checkbox, Image Grid, Text), and an optional generated reference distribution of 30 synthetic runs.
- **Synthetic profiles**, generated as data (no DOM events, no third-party sites): Slider adds *Stop-and-correct*; Drag & Drop (Direct, Eased, Noisy); Checkbox (Immediate, Delayed, Regular timing); Image Grid (Immediate, Uniform interval, Variable interval); Text (Uniform, Variable, Correction typing); Rotation (Direct, Eased, Overshoot-and-correct). Each sample records its profile, generator version (`synthetic@1`) and seed.
- **Experimental classifier** (`behavioral-baseline@1`): per-CAPTCHA rules turn configured, normalized signals into evidence, then into a balance and one of **Human-like**, **Synthetic-like** or **Uncertain**. The evidence is listed with strengths. There is no percentage, no "bot" label and no claim about real users. Lab data only.
- **Invisible / behavioral demo** (`/behavior/invisible`): after an explicit Start, a neutral click-the-target task is observed inside a pad, classified, and a *simulated* escalation suggestion is shown (Human-like → no extra challenge, Uncertain → Checkbox demo, Synthetic-like → Slider demo). Nothing is blocked or redirected. Keyboard works.
- **Learn**: a *Behavioral / Invisible CAPTCHA* section (signals, risk-based escalation, uncertainty, false positives and negatives, privacy, limitations). It is a lab module, not a thirteenth CAPTCHA.
- Evaluation panel: states that the classifier is experimental and shows how it reads each generated profile on the current challenge. With no labeled human data there is no accuracy figure or confusion matrix.

## Unchanged

All twelve CAPTCHAs, variants, difficulty and seeds work as before. Verification still checks only the challenge answer. The recorder and the plugin registry were not changed. Everything stays in the browser tab: no upload, no analytics, no storage, no fingerprinting.

## Limitations

The classifier is a hand-set rule baseline, not trained on real people. Noisy synthetic profiles can read as Human-like and straight human drags as Synthetic-like; the lab shows this on purpose. It is not a bot detector and not production security. Memory, Math, Sequence, Audio, Proof of Work and Shape Matching are not part of the Behavioral Lab yet. See `docs/behavioral-lab.md` and `docs/technical-debt.md`.
