# CaptchaLab v0.10.0-beta

The first beta. This release adds no new CAPTCHA family and does not change the classifier: it is about stability, accessibility, privacy consistency and documentation.

## Highlights

- **Browser Capability no longer exposes performance timing.** It now reports capability booleans only (does this API exist?). The check and computation durations were removed from the result, the feature set and the Inspect panel, because a duration reflects device performance. A regression test fails if timing comes back.
- **Hybrid ARIA / DOM ids corrected.** The two stages of a Hybrid challenge reused fixed ids (`try-h`, `inspect-h`, `metrics-h`, `events-h`), so a label could point into the wrong stage. Each stage is now scoped with its own prefix; a test checks every route for duplicate ids and for ARIA references with no target.
- **Accessibility pass.** Status regions announce Hybrid, Proof of Space, Proof of Work and Adaptive results. Inspect headings say what they hold (Behavioral metrics, Computation metrics, Environment capabilities).
- **Mobile.** Every public route is checked at 360, 390 and 400 px for horizontal overflow.
- **Documentation.** Expanded Learn sections for Hybrid, Invisible Lab and Adaptive Lab; new [privacy](../privacy.md) and [limitations](../limitations.md) pages; README product map.

## Unchanged on purpose

- `behavioral-baseline@1` (its checksum is pinned by tests) and the dataset format `captchalab-labeled-dataset@1`.
- Evaluation math and the Threshold Sandbox (which still works on a local copy).

## Known limits

See [limitations](../limitations.md). Notably: the classifier is hand-written, labels are user-provided, Drag & Drop has no complete keyboard alternative, and Chromium is the browser tested most.
