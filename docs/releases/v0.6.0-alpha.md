# CaptchaLab v0.6.0-alpha

A reproducible local research workbench: build a challenge, record sessions, generate deterministic synthetic ones, compare signals and evidence, export an experiment to a file, and import it again to reproduce it. Everything runs in the browser; nothing is uploaded, stored or tracked.

## New

- **Challenge builder** (`/builder`): choose a CAPTCHA (Slider, Drag & Drop, Checkbox, Image Grid, Text, Rotation), variant, difficulty and seed. Controls come from the plugins' own variant sets, invalid configurations are explained and never repaired, the seed changes only when you ask, and the preview is the real challenge, playable. Download or import it as `challenge-definition@1`; open it in Experiments or Compare with one click.
- **Experiments** (`/experiments`): one challenge, several locally recorded sessions, deterministic synthetic batches (run *i* uses `baseSeed + i`; at most 100 runs per batch, 300 in total), filters, per-cohort descriptive statistics that keep missing values missing, distribution strips, trajectories (Slider, Drag & Drop, Rotation) or timelines (Checkbox, Image Grid, Text) of selected sessions, and per-session classifier evidence. Classifier outputs are shown as counts, never as percentages or accuracy.
- **Versioned local files**: `challenge-definition@1`, `interaction-session@1`, `experiment-bundle@1` and a one-way `experiment-summary@1`. Strict readers, explicit version rejection, a size limit, depth and node limits, forbidden-key rejection, plain-text-only fields, and a checksum (not a signature). Synthetic batches are stored as recipes, so the same bundle always rebuilds the same sessions. See `docs/data-formats.md`.
- **New look**: a dark neon research-console theme (glass panels, blue-violet gradients, glow on the active item and primary actions, gradient titles) applied through the shared design tokens, so every page follows it. No behaviour changed.
- Documentation: `docs/experiment-workbench.md`, `docs/data-formats.md`.

## Unchanged

The recorder, the plugin contract, the signals (`behavior-signals@1`), the synthetic generator (`synthetic@1`) and the classifier (`behavioral-baseline@1`) are unchanged, and imported data never retunes the classifier. All twelve CAPTCHAs, Compare and the Invisible demo work as before. No backend, no analytics, no automatic storage, no fingerprinting.

## Limitations

Experimental local research tooling, not a scientific validation platform or a bot-detection benchmark. Only six CAPTCHAs are covered. Recorded sessions are local sessions, not a validated human dataset; there are no accuracy metrics. The classifier is still a hand-authored baseline. Nothing persists unless you download it. Experiment sizes are bounded. See `docs/technical-debt.md`.
