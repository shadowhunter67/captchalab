# CaptchaLab v0.2.0-alpha

Variants and difficulty for every CAPTCHA, a Vietnamese/English interface and a new app layout.

## What's new

- **Variants + difficulty + seed** on every challenge. The same seed, variant and difficulty always give the same challenge; links such as `/playground/text/?variant=noisy&difficulty=hard&seed=742193` open it exactly.
- **Slider:** Classic and Precision (narrower accepted release window per level).
- **Rotation:** Classic (narrower angle) and Offset start (starts further from upright).
- **Drag & Drop:** Shape match (smaller shapes and drop areas per level).
- **Text:** Clean, Rotated and Noisy (characters, rotation, shift and noise lines per level).
- **Image Grid:** Basic shapes and Similar shapes (circle/oval, square/rounded square); more matching cells at higher levels.
- **Checkbox:** one variant with a single level, on purpose: a checkbox has nothing that can honestly be made harder.
- **Challenge configuration** block in Inspect shows the variant, difficulty, seed and the parameters the level actually set, apart from the behavioral metrics.
- **Compare** keeps human and synthetic sessions on the same Slider configuration.
- Vietnamese by default with a VI / EN switch; three-column home with a live Session Inspector.

## Unchanged

Verification still checks only the challenge answer. Difficulty never affects the verdict or the behavioral features. Raw interaction data stays in the browser tab.

## Limitations

Not production CAPTCHA protection. No 4x4 grid, no "distorted" text variant and no Custom mode yet. See `docs/technical-debt.md`.
