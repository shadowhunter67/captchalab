# CaptchaLab v1.0.0

## Overview

CaptchaLab is an educational and research platform for exploring generic CAPTCHA and anti-abuse challenge families in a controlled environment. You try a challenge, then see what your own interaction looked like: the events, the signals, a replay, and an experimental reading by a hand-written classifier. Everything runs in your browser.

It is not a production bot detector, not a CAPTCHA bypass tool and not a replacement for any commercial anti-abuse system.

## What is included

- **Playground:** the challenges and composed labs, grouped by family (Visual, Cognitive, Audio, Computational, Behavioral, Environment, Hybrid), each with variants, difficulty levels and a seed.
- **Behavior and Compare:** behavioral signals and the experimental classifier `behavioral-baseline@1`, with a recorded attempt next to a generated one.
- **Builder, Experiments, Dataset and Evaluation:** reproducible challenge files, local experiments, a local labeled dataset, and a read-only evaluation of the classifier against those labels, with a Threshold Sandbox that only works on a copy.
- **Learn:** how each challenge works, what it does not prove, and the coverage matrix of what each entry supports.

## Stability and browser coverage

- Full automated regression in Chromium; a targeted smoke suite in Firefox and WebKit on every CI run. Real Safari and mobile browsers are not automated.
- Stale-run protection is tested for Memory, Audio, Proof of Work, Proof of Space and Hybrid. Audio reports clearly when a device cannot start audio output instead of hanging.
- Every public page is checked for broken internal links and anchors, duplicate ids, ARIA references with no target, and horizontal overflow at 360-400 px.

## Accessibility

Drag & Drop can be finished with the keyboard alone, with a pointer, or with both. Status changes are announced in live regions. This is not a WCAG certification, and the keyboard flows are not checked with every screen reader.

## Privacy

Raw interaction data stays in the browser tab: no analytics, no backend, no upload, no persistence. The dataset and experiments are in memory; exports and imports are user-triggered and local. Typed letters and digits are never recorded. Audio uses no microphone and no device enumeration. Browser Capability reports yes or no per API with no durations, hash, score or identifier. Details: [privacy](../privacy.md).

## Behavioral analysis and classifier limitations

The classifier is a set of hand-written rules. It is not trained on a real population, gives no percentage, and does not prove whether an interaction was made by a person or by software. Its label ("human-like", "synthetic-like", "uncertain") is an experimental reading of one interaction.

## Dataset and Evaluation

The dataset format is `captchalab-labeled-dataset@1`. A label is whatever the person typed; it is not verified ground truth and it is never the classifier's output. Evaluation leaves Unknown out, counts Uncertain on its own, computes accuracy over decided samples only, and shows "Insufficient sample" for small groups. The numbers describe the loaded data, not a security system.

## Known limitations

See [limitations](../limitations.md) and [technical debt](../technical-debt.md). In short: the classifier is hand-written and labels are user-provided; MatchKey, Tile Game, Proof of Space, Browser Capability and Proof of Work have no deep classifier support; Firefox and WebKit run only a smoke suite; Audio has one voice; Memory has no replay; Proof of Work and Proof of Space run on the main thread in bounded slices.

## From RC to final

v1.0.0 promotes the tested `v1.0.0-rc.1` codebase to stable after final production verification. No product code changed between the release candidate and 1.0.0: only status wording and these notes. The final production check added a complete MatchKey and a complete Tile Game interaction (select, verify, Passed) on the live site, which the release candidate's smoke had covered only up to page load.
