# CaptchaLab v0.8.0-alpha

A local **labeled dataset layer**: collect sessions, give each a label a person chose, keep the source apart from the label, and export or import the whole set. It prepares data for a later evaluation; it computes no accuracy and does not touch the classifier.

## New

- **Dataset page** (`/experiments/dataset`): a summary (total, labels, sources, CAPTCHA coverage, difficulties, variants, the current classifier's outputs as counts, and how complete each signal is), a table of sessions with the label, source and classifier reading side by side, a detail view, label editing, removal, single-record export, clear (with confirmation), export and import.
- **Labels are user-provided and separate from the classifier**: `human`, `synthetic`, `unknown`. A recorded session starts as `unknown` (recording does not make it human). A session CaptchaLab generated is `synthetic` with its provenance and a locked label. An imported record keeps the label the file declares. No label is ever derived from, or fed to, the classifier.
- **Add to dataset**, always explicit: from Compare (my session / the synthetic sample), from Experiments (per session) and from the Builder (an attempt). The challenge definition is kept with every record.
- **`captchalab-labeled-dataset@1`**: versioned, strict, deterministic export. See `docs/datasets.md`.
- **Careful import**: valid records are imported and the rest are rejected with a reason; signals and the classifier reading are always recomputed (the file's claims are shown as information and differences are reported); synthetic provenance is checked by regenerating the session; Memory's recall clock is validated as before; taken ids are renamed, never overwritten; size, depth, record and event limits apply.
- **Privacy hardening for every session reader**: a typing session that says *which key* was typed (`KeyA`, `Digit5`) is refused.
- Learn: a *Labeled data and evaluation* section on why a label is not the classifier's output.

## Unchanged

The classifier is still `behavioral-baseline@1` (its rules and ranges are pinned for all eleven CAPTCHAs by a test). Signals stay `behavior-signals@1` and the generator `synthetic@1`. The existing file formats are version 1 and still read. The dataset is in memory only: no localStorage, IndexedDB, backend, upload or analytics. Proof of Work is not part of behavioral datasets.

## Limitations

A user-provided label is not verified ground truth, and the dataset disappears on reload unless exported. No accuracy, precision, recall, F1, ROC or AUC is computed. Limits: 500 records, 300,000 events, 25 MB per file. See `docs/technical-debt.md`.
