# CaptchaLab v0.3.0-alpha

Three new CAPTCHAs, bringing the lab to nine. All use the variant, difficulty and seed system from v0.2.

## New

- **Shape Matching** (`/playground/shape-matching`): select a shape, then its counterpart. Variants: Exact shape and Pattern match (targets turned, outlined or resized). Difficulty adds pairs (3, 4, 5) and look-alike distractors.
- **Math / Logic** (`/playground/math-logic`): Arithmetic (up to two steps with correct precedence) and Comparison (type the larger value). Expressions are generated as data trees; there is no `eval`, and the typed answer is parsed strictly.
- **Sequence** (`/playground/sequence`): Number (steady step, multiplying or alternating steps, two interleaved rules) and Visual (repeating units of 2, 3 or 4 shapes). The generator rejects any puzzle where a simpler rule would give a different answer.
- `/playground` and `/learn` list all nine; Inspect shows the challenge configuration for each.

## Unchanged

Verification checks only the challenge answer. Raw interaction data stays in the browser tab; the Math and Sequence recordings store key classes, never which digit was typed.

## Limitations

Not production CAPTCHA protection. Compare still covers only the Slider. See `docs/technical-debt.md`.
