# CaptchaLab v0.4.0-alpha

Three more CAPTCHAs, bringing the lab to twelve. All use the variant, difficulty and seed system.

## New

- **Memory** (`/playground/memory`): watch a sequence of shapes or some lit cells, then recall them. Sequence memory (3, 4, 5 shapes) and Position memory (2, 4, 6 cells on a 3×3 or 4×4 grid). Press Start; the preview time is part of the challenge configuration.
- **Proof of Work** (`/playground/proof-of-work`): your device finds a nonce so that the SHA-256 of the challenge text and the nonce meets a low difficulty. Hash prefix and Leading zero bits variants. It runs in small chunks, never auto-starts and can be cancelled. The verifier recomputes the hash itself. This shows computational effort, **not** that a person did it; its metrics describe the computation, not the person.
- **Audio** (`/playground/audio`): listen to spoken digits and type them. Spoken digits and Digits with noise. The sound is made from small local clips plus seeded noise generated in the browser: no external service, no microphone, nothing recorded from you. The page links to a non-audio alternative.
- `/playground` and `/learn` list all twelve.

## Unchanged

Verification checks only the challenge answer. Raw interaction data stays in the browser tab; typed digits are stored as key classes only.

## Limitations

Not production CAPTCHA protection. Audio is English digits with one voice and cannot be used by deaf or hard-of-hearing people. Compare still covers only the Slider. See `docs/technical-debt.md`.
