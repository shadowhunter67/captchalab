# CaptchaLab v1.1.0

A realism pass. Nothing was added to the product's scope: the same challenges now look, feel and are operated like the
family of real CAPTCHA each one stands for. They stay generic, deterministic, local-only and non-proprietary.

## What changed

- **A challenge widget.** Every challenge's "Try" card is a light card with a prompt and one primary action; results, Inspect
  and the other lab panels stay in the dark console theme, outside it.
- **Pictures drawn in code** (14 objects, 5 scenes; [assets](../assets.md)): no image file, no download, nothing copied from any
  provider, nothing fetched at runtime. A challenge stores a category and a seed, so the same seed always draws the same picture.
- **Image Grid**: *Picture categories* and *Scene objects*, with look-alike distractors at the hard level and a rule that a tile
  that is not an answer never shows the target, even in the background. Tiles are named only "Image N of 9".
- **Slider**: *Puzzle piece* (a scene with a gap, and a piece that follows the handle). **Rotation**: *Upright picture*.
  **Drag & Drop** and **Shape Matching**: *Objects and silhouettes*. **MatchKey** and **Tile Game**: *object* variants.
- **Text**: a different font, ink, size and slant for each character, a speckled paper, curves and a mild wave, always readable.
- **System checks** (Proof of Work, Proof of Space, Browser Capability): working then verified, with the technical details collapsed.
- **Hybrid** has a two-step indicator; Invisible and Adaptive use the real flow's wording ("Start observation", "Suggested next challenge", still labelled experimental); Checkbox and Audio got a card and an icon.
- The Playground opens each family with its realistic variant. A named variant is always honoured, and Compare, Builder, Experiments and the dataset keep the plugins' own defaults.
- Learn says, for every challenge, which family it resembles and what is intentionally not cloned; the coverage matrix has a *Realistic presentation* column. See the [realism audit](../realism.md).

## Unchanged on purpose

`behavioral-baseline@1`, the dataset format `captchalab-labeled-dataset@1`, the Evaluation maths and the Threshold Sandbox,
every verifier's rule, and the privacy model. Variants that existed before draw exactly the challenges they always did.

## Known limits

See [limitations](../limitations.md): the pictures are drawings, the catalog is small, there is no 4x4 grid, and a person who
cannot see the pictures uses the audio challenge. Firefox and WebKit still run a smoke suite (it now includes the picture variants), not the full suite.
