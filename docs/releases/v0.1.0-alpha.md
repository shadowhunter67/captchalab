# CaptchaLab v0.1.0-alpha

First public alpha of **CaptchaLab**, an open-source educational and research lab for exploring CAPTCHA interaction, behavioral signals, and Human–Computer Interaction.

## Included

- Slider CAPTCHA
- Checkbox CAPTCHA
- Drag & Drop CAPTCHA
- Image Rotation CAPTCHA
- Text CAPTCHA
- Image Grid CAPTCHA
- Playground for all six CAPTCHA types
- Inspect tools for interaction events and behavioral features
- Event timeline and event inspector
- Trajectory and motion visualization where applicable
- Interaction replay
- Human vs synthetic Slider comparison
- Learn pages covering how each CAPTCHA works
- Local-first privacy model

## Privacy

Raw interaction data is processed locally in the browser by the current implementation and is not persisted or uploaded.

Text CAPTCHA key events store only coarse key classes rather than typed characters.

Synthetic comparison sessions are generated as in-memory CaptchaLab data and do not dispatch browser automation events.

## Project scope

CaptchaLab is intended for education, research, HCI experimentation, CAPTCHA analysis, and behavioral-analysis demonstrations in environments controlled by CaptchaLab.

It is not intended to bypass third-party CAPTCHA systems, solve commercial CAPTCHA services, or evade external anti-bot protections.

## Alpha limitations

- This is an early alpha release.
- Some accessibility limitations remain, especially for pointer-heavy challenges.
- Human vs synthetic comparison currently uses Slider as the reference CAPTCHA.
- CaptchaLab is not production CAPTCHA protection.
- Several known UX and replay edge cases are tracked as technical debt.
